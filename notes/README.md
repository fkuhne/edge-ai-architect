# notes/

Your technical notes and comprehension-checkpoint answers. Written for you, in
whatever form is useful — the point is that explaining something back to
yourself is where a lot of the learning lands.

Naming: `pNN-topic.md`, so notes sort by phase.

```
notes/p01-checkpoint.md      answers to the Phase 1 comprehension checkpoint
notes/p01-qat-vs-ptq.md      what the numbers actually showed and why
notes/p03-kv-cache-math.md   the derivation, worked on a real config.json
```

**This is not `book/`.** Notes hold the technical answer — what a result was,
what you understood. `book/log/` holds the raw narrative the same day: what you
expected, where you got stuck, what it felt like not to know yet. Notes can be
written later; log entries genuinely cannot. See [`../book/README.md`](../book/README.md).
